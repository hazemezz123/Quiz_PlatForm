# B. True / False Questions

## 1. Understanding hardware architecture and the operating system is essential for writing high-performance, reliable user programs.
**Answer:** True

## 2. The bootstrap program is stored on the hard disk and is loaded when the computer starts.
**Answer:** False

**Correction:** The bootstrap program is stored in ROM/EPROM (firmware), not on the hard disk.

## 3. From the system view, the operating system acts as a resource allocator that manages resources like CPU time, memory space, and I/O devices.
**Answer:** True

## 4. The Shell is part of the kernel.
**Answer:** False

**Correction:** The Shell is a system program associated with the OS but is not part of the kernel.

## 5. An Antivirus program is considered an application program.
**Answer:** False

**Correction:** An Antivirus program is generally considered a system utility (system program), not a regular application program.

## 6. The main goal of an operating system on a personal computer is to maximize resource utilization, even if it reduces convenience.
**Answer:** False

**Correction:** The main goal is to provide convenience, ease of use, and good performance for the user.
